# Пример сценария: заметка в Google Keep

## Подготовка (один раз)

1. На ПК подключить мост к Claude Code (по подписке пользователя, без API-ключа):

   ```
   claude mcp add --scope user wdpilot-mobile -- node "<путь>/workdesk-pilot-mobile/bridge/wdpilot-mobile.mjs"
   ```

   Или через файл `.mcp.json` в рабочей папке — см. `examples/mcp.json`.
   Брандмауэр Windows спросит про входящие подключения Node.js — разрешить для частной сети.
2. На телефоне (Android 11+) установить `WorkDeskAIPilot-debug.apk`, открыть, прочитать раскрытие и нажать
   «Согласен», включить службу в «Спец. возможностях» (если переключатель серый —
   «Приложения → WorkDesk AI Pilot → ⋮ → Разрешить ограниченные настройки»).

## Запрос в Claude Code

> Через wdpilot-mobile создай на моём телефоне в Google Keep заметку «Купить хлеб и молоко».
> Если телефон не подключён — скажи мне адрес и код.

## Что происходит

| Шаг | Инструмент | Кто действует |
|---|---|---|
| 1 | `status` → «Телефон не подключён… адрес ws://192.168.1.10:8765/pilot, код 123456» | Claude показывает адрес и код |
| 2 | — | человек вводит адрес и код в приложении и нажимает «Подключить» |
| 3 | `list_windows` → находит «Keep Заметки» (`allowed: true`) | Claude |
| 4 | `select_window` → на телефоне окно «Разрешить ИИ управлять «Keep Заметки»?» | человек нажимает «Разрешить» |
| 5 | `screenshot` → видит кнопку «+» внизу справа | Claude |
| 6 | `left_click` по «+», `screenshot` | Claude |
| 7 | `left_click` по полю «Заметка», `type` «Купить хлеб и молоко» | Claude |
| 8 | `key` Back → заметка сохранена, `screenshot` для проверки | Claude |
| 9 | `release_window` | Claude |

Вверху экрана всё это время горит красная кнопка «● ИИ: Keep Заметки ■ СТОП», в шторке — уведомление со «Стоп».
Любой «Стоп» мгновенно отзывает разрешение: следующий инструмент вернёт «Остановлено пользователем».

## Что ИИ сделать не даст

- `select_window` для Kaspi.kz, Halyk, Bitwarden, «Настроек», Google Play → отказ правилами.
- `type` в поле пароля или с номером карты → отказ, просьба к человеку.
- Действия, когда на экране другое приложение (пришёл звонок, человек переключился) → отказ до `focus_window`.
- Нажатие в кнопку «СТОП» → отказ.
