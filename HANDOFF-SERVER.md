## Только для телефона или ноутбука

- Проверка на реальных телефонах (One UI, HyperOS): эмулятор не воспроизводит оболочки производителей. Нужен телефон по USB/Wi-Fi с `adb` или ферма реальных устройств.
- Путь «iPhone через Mac»: нужен Mac с iPhone.
- iPhone как исполнитель невозможен (iOS не даёт управлять чужими приложениями).

## Как проверить

- Мост: `cd bridge && npm test`.
- Android: CI собирает и тестирует сам; артефакт `WorkDeskAIPilot-apk`.
- Эмуляторы: Actions → `e2e-emulators` → Run workflow; артефакты `e2e-<API>-<n>` (снимки, `result.json`).
