# Протокол «ПК ↔ телефон» (pilot, версия 1)

Один и тот же протокол для прототипа (телефон подключается к мосту в локальной сети) и для продукта
(телефон и ПК подключаются к релею workdesk.kz). Сообщения — JSON-текст в WebSocket, поле `t` — тип.

```
Claude Code ──MCP stdio──► мост wdpilot-mobile (ПК) ──ws──► исполнитель на Android (служба спец. возможностей)
                                      └── в продукте: ──wss──► workdesk.kz /api/pilot/ws ◄──wss── телефон
```

## Подключение (прототип)

`ws://<IP ПК>:8765/pilot`. Первое сообщение телефона — `hello` с одноразовым кодом, который мост показывает
на ПК (и в ответе инструмента `status`). Неверный код — закрытие 4401; после 5 неверных кодов мост меняет код.
Новый телефон с верным кодом вытесняет старый (у старого закрытие 4001).

| Код закрытия | Значение |
|---|---|
| 4400 | неверное сообщение (не JSON, не `hello` первым) |
| 4401 | неверный код |
| 4408 | нет `hello` за 10 с |
| 4426 | другая версия протокола |
| 4001 | подключился другой телефон |
| 1009 | сообщение больше 8 МБ |

## Телефон → мост

| `t` | Поля | Назначение |
|---|---|---|
| `hello` | `proto` (1), `code`, `device`, `android` (API), `app` (версия) | Первое сообщение |
| `result` | `id`, `content` (массив MCP: `text` / `image`), `isError` | Ответ на `call` |
| `stopped` | — | Человек нажал «Стоп» (кнопка на экране, уведомление, плитка) |

## Мост → телефон

| `t` | Поля |
|---|---|
| `welcome` | `proto`, `bridge` (версия) |
| `call` | `id`, `name` (один из 22 инструментов), `args` |

Мост ждёт ответ: `select_window` — 95 с (человек решает), `wait` — длительность + 10 с, остальное — 30 с.
При обрыве связи все ожидающие вызовы получают ошибку «телефон отключился».

## Инструменты

Те же 22 имени, что у `wdpilot` на ПК: 17 действий `computer_toolset_20260801` и 5 своих.
«Окно» на телефоне — это приложение.

| Инструмент | На телефоне |
|---|---|
| `list_windows` | приложения с иконкой запуска: `window_id`, `app`, `package`, `allowed` |
| `select_window` | окно «Разрешить ИИ управлять …?» на телефоне, затем приложение открывается |
| `release_window`, `focus_window`, `status` | как на ПК |
| `screenshot` | Android 14+: снимок только окна приложения; 11–13: экран целиком. JPEG, длинная сторона ≤ 1280 |
| `zoom` | фрагмент последнего снимка |
| `left_click` | нажатие (50 мс) |
| `right_click` | долгое нажатие (700 мс) |
| `double_click`, `triple_click` | 2 или 3 нажатия |
| `left_click_drag` | свайп 500 мс |
| `mouse_move` | запоминает точку; при прижатом пальце добавляет её в путь |
| `left_mouse_down` / `left_mouse_up` | жест по запомненному пути выполняется при отпускании |
| `cursor_position` | последняя точка касания |
| `scroll` | свайп; `down` показывает то, что ниже |
| `type` | вставка в поле в фокусе (`ACTION_SET_TEXT`), не в поле пароля |
| `key` | Return (`ACTION_IME_ENTER`), BackSpace, Back/Escape, Home, app_switch, ctrl+a/c/v/x |
| `middle_click`, `hold_key` | не поддерживаются (ошибка с подсказкой) |
| `wait` | пауза, прерывается «Стопом» |

## Релей workdesk.kz (следующий шаг, нужна правка консоли)

Предложение: маршрут `wss://workdesk.kz/api/pilot/ws?role=phone|host` с тем же токеном WorkDesk, что у
`/api/claude/ws`. Сервер пересылает `call`/`result`/`stopped` только между устройствами **одной учётной записи**;
вместо кода — выбор телефона из списка (`t: "list"` → `phones`). В журнал (`audit_events`, `kind = 'pilot'`)
пишутся выбор приложения, «Стоп» и имена инструментов, без снимков и введённого текста.
Агент `workdesk-claude` на ПК подключает мост как MCP-сервер, так что задачу можно дать и с телефона
(вкладка Claude в WorkDesk AI), и в Claude Code на ПК.
